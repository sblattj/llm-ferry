# llm-ferry v1.49.1 — the domestic guard catches Xiaomi, inclusionAI and more

The domestic-fleet guard missed several Chinese labs. A route config that pointed a `domestic.*` lane at `xiaomi/mimo-v2.6-pro` or `inclusionai/ling-3.0` loaded without complaint, and the per-request check let it through. This release closes those gaps, checked against every author in the live OpenRouter catalogue.

[Read the project overview](https://github.com/sblattj/llm-ferry/blob/main/README.md)

## Fixed

- The guard now refuses Xiaomi (MiMo), inclusionAI / Ant Group (Ling, Ring, Bailing), dots (RedNote) and Nex AGI. It also covers Kuaishou (KAT), Skywork/Kunlun, OpenBMB (MiniCPM), Zhipu's THUDM/Cog models, XVERSE, Huawei (Pangu), BAAI, INF, InternVL, 360 Zhinao, TeleChat, and Tencent/ByteDance model names that carry no lab prefix.
- Ling and Ring are matched only with a version or size suffix (`ling-3.0`, `ring-flash`), so words such as `string-1` or `ceiling` don't trip the guard.
- Of 465 model ids from 63 OpenRouter authors, all 139 from Chinese labs are now flagged (126 were before). None of the other 326 is flagged.

## Tests

- `lib/ferry-fleetguard.test.py`: positive cases for each added family, English-word lookalikes, five US models that must pass, and the route template still passing.

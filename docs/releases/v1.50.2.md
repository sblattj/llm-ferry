# llm-ferry v1.50.2: goal plugin 1.5.3

ferry now pins version 1.5.3 of the OpenCode goal plugin (`opencode-goal-pro-max-complete-plugin`), its latest release. 1.5.3 is on npm now, and its shipped `src/` and `dist/` are byte-identical to 1.5.2, so goal sessions behave exactly as before.

[Read the project overview](https://github.com/sblattj/llm-ferry/blob/main/README.md)

## Changed

- **Goal plugin pinned to `v1.5.3`** (was `v1.5.2`). Only the plugin's docs, `package.json` version, examples and installer help text changed. Nothing ferry installs or configures changes: no new options, config keys, bundled files, install layout or `tui.json` entry.
- The pinned spec changes, so OpenCode installs the new version fresh. The old 1.5.2 entry is still recognized by package name and replaced.
- The bundled `using-the-goal-plugin` skill is byte-identical at the `v1.5.3` tag, so its copies in `opencode/skills/` and `client-bootstrap.sh` are unchanged apart from the tag named in a comment.

## Tests

- `lib/ferry-integrate.test.py` and `lib/ferry-clientbootstrap.test.py` now expect the `v1.5.3` spec and version.

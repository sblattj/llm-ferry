# llm-ferry v1.50.1: goal plugin 1.5.2

ferry now pins version 1.5.2 of the OpenCode goal plugin (`opencode-goal-pro-max-complete-plugin`), its latest release. 1.5.2 is a contributor-facing release: the plugin's shipped `src/` and `dist/` are byte-identical to 1.5.1, so goal sessions behave exactly as before.

[Read the project overview](https://github.com/sblattj/llm-ferry/blob/main/README.md)

## Changed

- **Goal plugin pinned to `v1.5.2`** (was `v1.5.1`). The plugin moved its development and CI to Bun, kept its `npx` installer on Node, and documents Windows as unsupported. Nothing ferry installs or configures changes: no new options, config keys, bundled files, install layout or `tui.json` entry.
- The pinned spec changes, so OpenCode installs the new version fresh. The old 1.5.1 entry is still recognized by package name and replaced.
- The bundled `using-the-goal-plugin` skill is byte-identical at the `v1.5.2` tag, so its copies in `opencode/skills/` and `client-bootstrap.sh` are unchanged apart from the tag named in a comment.

## Tests

- `lib/ferry-integrate.test.py` and `lib/ferry-clientbootstrap.test.py` now expect the `v1.5.2` spec and version.
